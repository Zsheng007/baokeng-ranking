## GitHub 推送应急：Git Data API（本次网络故障）
- 现象：github.com 全节点经代理 000/502，但 **api.github.com 走代理正常(200)** → git push 不可用，API 可用
- 方案：`POST /git/blobs`(base64) → `POST /git/trees`(base_tree=远端HEAD tree) → `POST /git/commits`(parents=[HEAD]) → `PATCH /git/refs/heads/main` 完成模拟推送（远端 c8132b8→9e3b4f5）
- ⚠️ 分叉：API 生成的 commit 与本地 git 历史不同 → 本地仍领先3个commit(00e0075/029eb86/f7ccf38)，内容与远端一致；网络恢复后 `git fetch && git reset --hard origin/main` 对齐（内容相同无损）
